# Bundled fonts

Latin variable WOFF2 files from Google Fonts, bundled to avoid build-time font downloads.

- Manrope: weights 200 to 800; see MANROPE-OFL.txt.
- Inter: weights 100 to 900; see INTER-OFL.txt.

Sources:

- manrope: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- inter: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2
